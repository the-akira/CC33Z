O que é lógica de programação?

Programar é dar instruções específicas e claras, em ordem, para uma máquina poder executá-las. Aqui você monta um programa com blocos e vê o robô executá-lo. Em cada fase você aprende um conceito: sequência, repetição, condição, laço com condição, variável, função e algoritmo.
