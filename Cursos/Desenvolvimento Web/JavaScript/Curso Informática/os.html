O que é um Sistema Operacional?

O sistema operacional (SO) é o software que fica entre os programas e o hardware. Ele tem dois papéis: gerenciar recursos (CPU, memória, disco, rede) para que vários programas dividam a máquina sem brigar, e oferecer uma interface simples para que ninguém precise programar o disco ou a placa de vídeo na mão. Windows, Linux, macOS, Android e iOS são sistemas operacionais.

    Modo Usuário, Modo Kernel e Chamadas de Sistema

    A CPU tem níveis de privilégio. Aplicativos nunca acessam o hardware diretamente

    Quando um programa quer abrir um arquivo, ele não toca no disco: executa uma instrução especial (trap) que transfere o controle ao kernel. O kernel confere as permissões, faz o trabalho e devolve o resultado.
