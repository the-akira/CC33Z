Da raiz ao arquivo: como o computador organiza tudo em uma estrutura de árvore

Organização do Computador

O computador organiza tudo o que é salvo em uma estrutura de árvore: tudo começa em uma raiz (o próprio disco de armazenamento) e, a partir dela, se ramifica em diretórios (pastas), que podem conter outros subdiretórios e arquivos. Explore o painel abaixo como se fosse o Explorador de Arquivos do Windows.

    Glossário

    Os principais conceitos dessa estrutura em árvore

    💽

    Raiz

    É o ponto de partida de toda a árvore de diretórios — representa o próprio disco de armazenamento (ex: C:\ no Windows ou / no Linux). Todos os diretórios e arquivos existem "dentro" dela.

    📁

    Diretório (Pasta)

    É um "container" que organiza arquivos e outros diretórios. Um diretório pode conter vários subdiretórios, formando ramificações da árvore.

    📂

    Subdiretório

    É um diretório que está dentro de outro diretório. A relação entre eles é chamada de diretório pai (o de cima) e filho (o de dentro).

    📄

    Arquivo

    É a unidade que guarda os dados em si (texto, imagem, música, programa). Diferente do diretório, o arquivo não pode conter outros itens dentro dele — ele é sempre uma "folha" da árvore.

    🧭

    Caminho Absoluto

    Mostra a rota completa desde a raiz até o item, por exemplo: C:\Usuários\Estudante\Documentos\carta.txt. Funciona de qualquer lugar do sistema.

    🔗

    Caminho Relativo

    Mostra a rota a partir de onde você já está, sem repetir tudo desde a raiz. Por exemplo, estando em Documentos, o caminho relativo para o arquivo relatorio.docx seria apenas Trabalho\relatorio.docx.
